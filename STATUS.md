# Trạng thái so với kế hoạch full game

Không có mốc full-game nào được đánh dấu hoàn thành chỉ dựa trên số binding.

Ưu tiên hiện tại: chạy trọn game trước, multiplayer gameplay làm sau. Main Lua
đã trả về; callback Start còn dừng tại AddTextWidget, chưa có world chạy được.

## Hợp đồng tương thích đã xác nhận

- Build: 756039; Lua: 5.1; bytecode portable/header khác kiến trúc chưa xử lý đầy đủ.
- Tick duration: 0.03333333507180214.
- Lua RNG: PCG32; multiplier 0x5851f42d4c957f2d, increment 0xb47c73972972b7b7; native wrapper chia uint32 cho 4294967295.
- Native RNG functions: seed 0x140438e20, output 0x140438c60, Lua random 0x1404fcd10 trong client x64 đã phân tích. Cần đối chiếu thêm integer ranges và những RNG khác của engine.
- Persistent-string envelope: KLEI%6d%c, version 1; loại space là plain, loại D là Base64 với header bốn uint32 và zlib + Adler32. Các biến thể chưa thấy phải bị từ chối.
- Persistent-string Lua API cắt tại NUL cả khi ghi và callback đọc, kể cả file được tạo ngoài engine có byte sau NUL. Tham số nén chỉ nhận boolean; có thể bỏ nó để truyền callback ở vị trí kế tiếp. Native fixture kiểm tra plain/compressed/omitted/non-boolean và thứ tự callback.
- Save decoder hiện chỉ trả metadata sau khi giải mã; không gọi world-network functions để dựng gameplay.
